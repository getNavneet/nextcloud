# Nextcloud (Docker Compose Setup)

Nextcloud is an **open-source, self-hosted cloud platform** that lets you store, sync, and share files, similar to Google Drive, but with full control over your data.

## Requirements
- Docker

## How to Run

- ```docker compose up -d```

- Open Nextcloud in your browser:
   http://localhost:8080 


Create an admin account

Database type: `MariaDB`

Database user: `nextcloud`

Database password: `nextcloudpass`

Database name: `nextcloud`

Database host: `db`
